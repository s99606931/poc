## 회의 준비 — 핵심 메시지

> 고객사 미팅 전 반드시 숙지: [내부 회의 결정 사항](./01-internal-meeting.md)

### 가장 많이 받는 질문에 대한 공식 답변

```
Q. "AI를 학습시켜야 하나요? 우리 데이터를 학습에 사용하면 유출 위험은 없나요?"

A. 이번 POC는 AI 학습(Fine-tuning)이 아닙니다.
   규정 문서를 검색 가능한 형태로 구조화하는 RAG 방식입니다.
   AI 모델 자체는 변경하지 않으며, 규정 문서는 기관 내부망 서버에만 저장됩니다.
   인터넷 연결 없이 완전 내부망에서 동작합니다.
   → 상세: poc/README.md — "AI 접근 방식 명확화" 섹션
```

```
Q. "오픈소스 AI 모델을 쓰면 품질이 나쁘지 않나요?"

A. 이번 POC에 사용할 Google Gemma 4 모델은 Apache 2.0 라이선스 오픈소스이며,
   행정 문서 생성과 다국어(한국어) 처리에서 우수한 성능을 보입니다.
   별도 라이선스 비용이 없어 내부망 무제한 활용이 가능합니다.
   → 상세: poc/improvements/ai-llm.md — "LLM 모델 선택 기준" 섹션
```

```
시나리오 A: A40 48GB 이상 보유 → 즉시 POC 착수 가능
시나리오 B: 구형 GPU (RTX급) 보유 → 단일 모델로 범위 조정 협의
시나리오 C: GPU 없음 → 신규 구매 협의 (리드타임 2~3개월 주의)
```

| "본 사업 비용은 얼마나 되나요?" | POC 성과 기반으로 별도 협의 (현재는 POC 범위만) |
