## 1. ERP 시스템

| 요건 | 설명 |
|------|------|
| 접근 방식 | sql-runner Read-Only |
| 필요 뷰 | `V_ALLI_ACC_EXPENSE_HIST`, `V_ALLI_BDG_BALANCE`, `V_ALLI_ACC_EXPENSE_LIMIT` |
| 조회 대상 | 개인/부서 과거 지출·예산 잔액·지출 한도 |

## 2. 그룹웨어 시스템 — **🔴 P0-1 중요**

| 요건 | Read | Write |
|------|:---:|:---:|
| 결재선 조회 | ✅ 필수 | — |
| 양식 조회 | ✅ 필수 | — |
| **기안 초안 등록** | — | ✅ **필수** |
| 첨부파일 업로드 | — | ⚠️ 권장 |

**Write 권한 미확보 시**: 기안 **초안 저장만**으로 POC 진행, 실제 등록은 담당자 수동.
**대안**: [../decisions.md#-d2-06-미확정-시-영향](../decisions.md)

## 3. 고객 사전 제공 필요

```
□ 결재 양식 서식 3종 (출장비/물품구매/초과근무)
□ 기존 기안문 샘플 각 10건 (Few-shot 학습용)
□ 결재 규정 문서 (지출 한도·결재선 기준)
□ 결재선 규칙 기준표 (금액별 결재자 단계)
□ 그룹웨어 API 문서 (API Key or DB 계정)
□ 결재 문서 ID 생성 규칙 (그룹웨어 벤더 준수)
```

## 4. 리스크

| 리스크 | 대응 |
|--------|------|
| 그룹웨어 Write 권한 미확보 | 초안 저장 모드로 축소 |
| 기안문 품질 미달 | Few-shot 5종 + 담당자 수정 UI |
| 결재선 오류 | 추천만, 사용자 확인 후 등록 |
| 첨부파일 자동 | POC 범위 제외 (수동 첨부) |
