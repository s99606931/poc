# 위반 항목 분류 및 감점 기준

## 1. 위반 유형별 감점

```python
VIOLATION_WEIGHTS = {
    "필수항목_누락": 25,       # 법정 필수 기재 사항
    "금액_불일치": 20,         # 품의금액 ≠ 계약금액
    "결재선_오류": 15,         # 전결 규정 위반
    "기간_오류": 15,           # 유효기간/납품기한
    "서식_불일치": 10,         # 공식 서식 미사용
    "표현_오류": 5,            # 법정 용어 오사용
}
```

## 2. 문서 유형별 필수 항목

| 문서 유형 | 필수 항목 |
|----------|---------|
| 품의서 | 제목, 품의금액, 품의사유, 결재선, 예산과목, 기안자 |
| 계약서 | 계약당사자, 계약금액, 계약기간, 납품기한, 하자보증 |
| 출장명령서 | 출장지, 출장기간, 출장목적, 교통수단, 예상비용 |
| 공문서 | 수신, 참조, 제목, 본문, 기안자, 문서번호 |
| 회의록 | 회의명, 일시, 장소, 참석자, 안건, 결의사항, 작성자 |
| 입찰공고 | 입찰번호, 사업명, 예산금액, 입찰방법, 제출기한, 낙찰방법 |

## 5. 위반 판정 수준 (고객 결정 D5-02)

### 엄격 모드
```python
STRICT_MODE = {
    "confidence_threshold": 0.70,   # 70% 이상 확신 시 위반 표시
    "max_violations_shown": 50,
}
```

### 균형 모드 (권장)
```python
BALANCED_MODE = {
    "confidence_threshold": 0.80,
    "max_violations_shown": 20,
}
```

### 관대 모드
```python
LENIENT_MODE = {
    "confidence_threshold": 0.90,   # 90% 이상만
    "max_violations_shown": 10,
}
```
